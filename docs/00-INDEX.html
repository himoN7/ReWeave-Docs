ReWeave Documentation Index

This folder contains comprehensive documentation for ReWeave — a Windows App SDK / WinUI 3 fabric simulation studio for weave design, 2D yarn-interlaced preview, and academic 3D geometry models.

Key Features

  • 2D weave design with infinite canvas
  • 2D simulation with continuous yarn ovals
  • 3D simulation with multiple yarn path models
  • 27 built-in weave patterns
  • Model builder with AI assistance
  • Advanced fabric physics simulation
