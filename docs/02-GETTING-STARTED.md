# Getting Started with ReWeave Studio

Quick start guide for end users and textile designers.

## Quickstart Guide

### 1. Launch ReWeave Studio
Open ReWeave from your Windows Start menu or shortcut. On first launch, the Home Page displays available project templates and recent files.

### 2. Create Your First Weave Design
1. Select **Weave Design Studio** from the category bar or navigation menu.
2. Choose a template from the **27 Built-in Patterns** (Plain Twill, Satin, Waffle, Honeycomb).
3. Customize warp and weft yarn repeat colors using the RGB color pickers.

### 3. Preview 3D Yarn Geometry
1. Switch to the **3D Simulation Viewport**.
2. Select your desired analytical yarn model (e.g., Circular, Spline, or Bézier).
3. Inspect high-resolution 3D yarn interlacement and surface PBR textures.

### 4. Run Fabric Physics & Drape Simulation
1. Open the **Fabric Physics Engine**.
2. Click **Run Simulation** to preview real-time fabric drape and tension dynamics.
3. Scrub the interactive timeline to evaluate drape metrics.

### 5. Export Your Project
Use **File → Export** to save your work as `.weave` projects, `.wif` loom files, 3D `.obj` meshes, or PNG technical spec sheets.
