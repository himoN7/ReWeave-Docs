Developer Setup

Step 1: Clone Repository

git clone https://github.com/yourusername/WinUi-ReWeave.git
cd WinUi-ReWeave

Step 2: Install Visual Studio Workload

If Visual Studio 2022 is not installed:

  1. Download Visual Studio Community 2022
  2. Run installer
  3. Select Windows App SDK workload
  4. Under "Individual components," ensure:
    • .NET 8 SDK installed
    • C# language support enabled
  5. Complete installation

If Visual Studio is already installed:

  1. Open Visual Studio Installer
  2. Click Modify on Visual Studio 2022
  3. Add Windows App SDK workload (if not present)
  4. Click Modify

Step 3: Restore Dependencies

# Using dotnet CLI
dotnet restore

# Or let Visual Studio handle it automatically on first open

Step 4: Verify Installation

# Check .NET 8 SDK
dotnet --version

# List installed SDKs
dotnet --list-sdks

# Should show 8.x.xxx in the output

Building

Command Line Build

Build for x64 Debug:

cd "WinUi ReWeave"
dotnet build -p:Platform=x64 -c Debug

Build for x64 Release:

dotnet build -p:Platform=x64 -c Release

Build for x86:

dotnet build -p:Platform=x86 -c Debug

Build all platforms:

dotnet build -p:Platform=x64 -c Debug
dotnet build -p:Platform=x86 -c Debug
dotnet build -p:Platform=ARM64 -c Debug  # ARM64 on native machine only

Visual Studio Build

  1. Open WinUi ReWeave.slnx in Visual Studio
  2. Select platform: x64 (preferred for development)
  3. Select configuration: Debug
  4. Build → Build Solution (Ctrl+Shift+B)

Build output location:

WinUi ReWeave/bin/x64/Debug/

Build Issues & Solutions

Issue Solution
.NET 8 SDK not found Install .NET 8 SDK from dotnet.microsoft.com
Windows App SDK missing Install via Visual Studio Installer workload
Cannot find WinUI Run dotnet restore to restore packages
Namespace X not found Clean solution, rebuild (Visual Studio may need restart)
"rimraf" command not found Install Node.js (required for some build tasks)

Running Locally

From Visual Studio (Recommended for Development)

  1. Open WinUi ReWeave.slnx
  2. Ensure x64 is selected as active platform
  3. Press F5 or Debug → Start Debugging

Debugging Features:

  • Set breakpoints by clicking line numbers
  • Step through code (F10, F11)
  • Inspect variables in debugger
  • Watch window (Ctrl+Alt+W)
  • Immediate window (Ctrl+Alt+I)

From Command Line

# Build and run
cd "WinUi ReWeave"
dotnet build -c Debug
dotnet run

# Or directly run published build
dotnet publish -c Release -p:Platform=x64
# Find .exe in publish folder and run

Testing Locally

Run all tests:

dotnet test

Run specific test project:

dotnet test ReWeave.AutomatedTests/ReWeave.AutomatedTests.csproj

Run with coverage (if configured):

dotnet test /p:CollectCoverage=true

Publishing & Deployment

MSIX Bundle (Recommended)

MSIX is the modern Windows package format. One file contains x86 + x64 + ARM64.

Prerequisites

  1. Test Certificate (for signing):

    cd scripts
./create-test-certificate.ps1 -TrustOnThisMachine

    Creates: certs/WinUiReWeave-Test.pfx Password: ReWeaveTest (or configured value)

  2. Trust Certificate (first time only):

    ./trust-test-certificate.cmd

Build MSIX Bundle

Via Publish Script:

publish-msix.cmd

Or PowerShell (if scripts blocked):

powershell -ExecutionPolicy Bypass -File .\scripts\publish-msix.ps1

Or Visual Studio:

  1. Right-click project
  2. Publish → msix profile
  3. Follow prompts

Output Location:

dist/WinUi ReWeave_<version>_x86_x64_arm64.msixbundle

One-Click Install

Double-click install-msix.cmd — it auto-detects the newest bundle in dist\, trusts the test certificate (single UAC prompt, idempotent), and runs Add-AppxPackage. Use this instead of the manual trust + Add-AppxPackage steps above.

Share with other PCs

prepare-release.cmd

This creates release/ with everything in one place: Install.cmd, WinUiReWeave-Test.cer, and the signed .msixbundle. Zip that folder and send it — the recipient only double-clicks Install.cmd (one UAC prompt); no repo or other files are needed.

Store submission: pass -StorePublish to publish-msix.ps1 (with -c Release) to build an unsigned StoreUpload bundle instead of a locally-signed sideload bundle — Partner Center signs the upload on ingestion.

Publishing on Microsoft Store

  1. Reserve App on Partner Center

    • Get Product Identity Name
    • Get Publisher ID

  2. Update Package Manifest:

    • Edit Package.appxmanifest
    • Set Identity Name to match Partner Center
    • Set Publisher to match

  3. Rebuild & Publish:

    publish-msix.cmd

  4. Upload .msixbundle to Partner Center → Packages

  5. Submit for certification

Portable Executable (Alternative)

Unpackaged Distribution:

dotnet publish \
  -c Release \
  -p:Platform=x64 \
  -p:PublishUnpackagedExe=true \
  -o ./publish-win-x64-unpackaged

Output: Single .exe file with all dependencies

Note: Requires .NET 8 runtime on target machine

Manual Distribution

  1. Create Package:

    publish-msix.cmd

  2. Sign & Verify:

    Get-AuthenticodeSignature dist/WinUi*.msixbundle

  3. Test Install (before distribution):

    Add-AppxPackage -Path "dist/WinUi ReWeave_<version>_x86_x64_arm64.msixbundle"

    Or one-click: install-msix.cmd (trusts the cert + installs).

  4. Distribute:

    • Host on website
    • Email to users
    • GitHub releases
    • Microsoft Store

Configuration Files

Build Configuration

WinUi ReWeave.csproj:

<PropertyGroup>
    <Version>0.4.0</Version>
    <TargetFramework>net8.0-windows10.0.19041.0</TargetFramework>
    <Platforms>x86;x64;ARM64</Platforms>
    <!-- More settings... -->
</PropertyGroup>

Update Version:

  1. Edit WinUi ReWeave.csproj
  2. Change <Version> tag
  3. Rebuild

Package Manifest

Package.appxmanifest:

<Package>
    <Identity Name="ReZephyr.ReWeave" Publisher="CN=2AF31A40-66FB-4D26-826C-C2AD1251C019"/>
    <Properties>
        <DisplayName>ReWeave</DisplayName>
        <PublisherDisplayName>ReZephyr</PublisherDisplayName>
    </Properties>
</Package>

To Update Publisher:

  1. Edit Package.appxmanifest
  2. Change Publisher attribute
  3. Regenerate certificate to match
  4. Rebuild package

Troubleshooting Setup Issues

"Windows App SDK not installed"

Solution:

# Check installed versions
Get-AppxPackage -Name "WindowsAppRuntimeMain"

# If not found:
# 1. Open Visual Studio Installer
# 2. Modify Visual Studio 2022
# 3. Install "Windows App SDK" workload
# 4. Restart computer

".NET 8 SDK not found"

Solution:

  1. Download .NET 8 SDK
  2. Run installer
  3. Verify: dotnet --version shows 8.x.xxx
  4. Restart Visual Studio

"Project file not found"

Solution:

# Ensure you're in correct directory
cd "WinUi ReWeave"
ls *.csproj  # Should list the .csproj file

# Try explicit path
dotnet build "WinUi ReWeave.csproj"

"Cannot open package"

Solution:

# Run Visual Studio as Administrator
# Right-click: Run as Administrator
# Then open solution

# Or rebuild from command line:
dotnet clean
dotnet restore
dotnet build

Build succeeds but app won't launch

Solution:

  1. Check platform matches (x86 vs x64)
  2. Ensure correct startup project selected
  3. Clean and rebuild:
    dotnet clean
dotnet build
  4. Try launching from: bin/x64/Debug/WinUi ReWeave.exe

"Namespace not found" errors after restore

Solution:

# Clean and restore
dotnet clean
dotnet restore

# Restart Visual Studio
# Then rebuild

Certificate issues with MSIX

Solution:

# Remove old certificate
Remove-Item certs/WinUiReWeave-Test.pfx

# Create new certificate
./scripts/create-test-certificate.ps1 -TrustOnThisMachine

# Trust on current machine
./scripts/trust-test-certificate.cmd

# Rebuild package
publish-msix.cmd
