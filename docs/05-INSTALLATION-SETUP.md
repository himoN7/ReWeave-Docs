# Installation & System Requirements

Installation guide and minimum platform requirements for ReWeave Studio.

## System Requirements

### Minimum System Requirements
- **Operating System:** Windows 10 (Version 1809 or later) / Windows 11
- **Architecture:** x64 or ARM64
- **Graphics Hardware:** Direct3D 11 compatible GPU with 2GB VRAM
- **Memory:** 4 GB RAM
- **Storage:** 250 MB free disk space

### Recommended Specifications
- **Operating System:** Windows 11 (22H2 or later)
- **Processor:** Multi-core Intel Core i5 / AMD Ryzen 5 or Apple M-series (via Windows ARM64)
- **Graphics Hardware:** Direct3D 11 GPU with 4GB+ VRAM
- **Memory:** 8 GB+ RAM

## Installation Options

### 1. MSIX Package (Recommended)
Download the `ReWeave_x64_ARM64.msixbundle` installer and double-click to install natively on Windows 10/11.

### 2. Standalone Portable Deployment
Download the self-contained portable package. No administrator privileges or external framework installations required.
