# Deployment & Release Overview

High-level summary of application distribution channels and packaging formats.

## Distribution Channels

### Microsoft Store Publishing
ReWeave Studio is packaged for digital distribution via the Microsoft Store for Windows 10 and Windows 11 PCs.

### Enterprise MSIX Packaging
Self-contained `.msixbundle` installer packages are signed for enterprise sideloading and IT administration deployment.

### Automatic Updates
Installed versions check for feature updates and security patches through native Windows App SDK deployment pipelines.
