# ReWeave Feature Matrix

Comprehensive summary of core capabilities and product modules in ReWeave Studio.

## Product Modules

### 1. Fabric Physics & Drape Simulation
- Real-time sheet drape modeling powered by XPBD.
- Standardized fabric drape coefficient calculation.
- Dynamic tension handles and timeline playback.

### 2. Unit Cell Strain Bench
- Simulated uniaxial tensile loading and strain heatmaps.
- Trellis pure shear testing and crossover angle analysis.
- Cantilever bending and transverse compression modes.

### 3. 3D Yarn Path Modeling & Rendering
- 6 analytical yarn path geometry models (Peirce, Kemp, Fourier, Spline, Bézier, Float Compensation).
- Photorealistic PBR surface rendering with customizable fiber parameters.
- High-density 3D mesh export (.OBJ, .DXF, .STL).

### 4. 2D Weave Design Studio
- Infinite matrix canvas for dobby and jacquard pattern authoring.
- 27 built-in textile pattern templates.
- Full warp/weft color repeat sequences and WIF file support.

### 5. AI Vision & Fabric Image Analysis
- Automated weave structure detection from fabric macro photos.
- CLAHE contrast enhancement and 2D FFT yarn density estimation.

### 6. Desktop Platform & Distribution
- Native WinUI 3 desktop user interface with Fluent Design 2.
- Self-contained MSIX installer for Windows 10/11 (x64/ARM64).
