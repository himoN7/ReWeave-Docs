Audience: All Users, Trainers, Support

Conflict notes

  • Ctrl+S always saves the project. Pattern-library save on Geometry is Ctrl+Alt+S.
  • Space / F / F10 / Ctrl+R are page-scoped (Physics vs Strain Bench vs Geometry) — same verbs where the action exists.
  • Ctrl+O opens a project globally; Analyzer photo import is Ctrl+I.
