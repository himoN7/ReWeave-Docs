# Desktop Platform & Packaging Architecture

Overview of Windows platform integrations and native desktop distribution.

## Platform Integration Features

### Native Windows Integration
Built natively using Windows App SDK and WinUI 3 to deliver modern Fluent Design 2 visual aesthetics, Mica window materials, and system light/dark mode adaptation.

### Multi-Architecture Support
Compiled for native execution on both x64 Intel/AMD processors and ARM64 Windows devices.

### Self-Contained Deployment
Zero prerequisite dependencies required. All necessary .NET 8 runtimes and Windows App SDK libraries are bundled directly inside the installer.
