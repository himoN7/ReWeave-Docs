Privacy policy

Last updated: 3 November 2026 Product: ReWeave (ReZephyr)

This policy describes how ReWeave handles information when you use the Windows desktop app. ReWeave does not require an account, and ReZephyr does not sell personal information.

The public copy used by the Microsoft Store listing is https://himon7.github.io/ReWeave-Docs/privacy-policy.html.

Information stored on your PC

Depending on how you use the app, ReWeave stores:

  • Project files you save (.reweave), including an optional encrypted form
  • Settings, recent projects, and local libraries (weaves, colours, yarns, presets)
  • Weaver chat history, saved prompts, and design memory for the open project
  • A local reliability record and, if the app closes unexpectedly, one crash log you can choose to send
  • Optional Weaver usage statistics that record outcome, duration, mode, and model name, and do not record your messages, designs, or file paths

You control where projects are saved. Uninstalling the app may leave documents and %LocalAppData%\ReZephyr\ReWeave until you delete them.

For every local file and every network request, see the data disclosure.

Network

Design, geometry, physics, and mechanical tests work offline. ReWeave does not upload projects or simulation results to a ReZephyr server.

A network request happens only when you start one:

  • Weaver with a cloud provider. If you turn on Anthropic Claude, OpenAI, Google Gemini, or an OpenAI-compatible endpoint, that turn sends your message, recent chat, and the draft details Weaver needs. The API key stays on this PC, protected with Windows DPAPI. With providers off, Weaver stays on the built-in offline rules.
  • A local model you configure. If you point Weaver at an address such as Ollama or LM Studio, the request goes to that address.
  • Update check and links. Checking for updates, opening documentation, or emailing support uses the network or your browser.

Children

ReWeave is not directed at children under 13.
