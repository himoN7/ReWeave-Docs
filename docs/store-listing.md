## Description

ReWeave is a Windows studio for woven fabric.

Draw a dobby or layered draft, colour the warp and weft, and keep the project in a `.reweave` file on your PC. Geometry shows the yarn paths. Physics and mechanical tests explore drape, tension, and standard analytical tracks. Several mechanical results are labelled as analytical proxies, not a laboratory measurement.

Weaver can suggest draft changes. It runs offline on built-in rules. A cloud model runs only if you turn on a provider and enter your own API key.

This edition saves and reopens ReWeave projects. Export to loom, image, and CAD files is not included. Jacquard editing, the model builder, and the photo analyzer are not in this edition.

No account is required. Design and simulation work offline.
